# assets/persona

Use esta pasta para colocar seus próprios arquivos visuais que quiser usar na interface.

Exemplos válidos:
- PNG
- JPG
- WEBP
- SVG
- GIF

Estrutura recomendada:
- persona/cover.png
- persona/target.png
- persona/portrait.webp
- persona/mission-sheet.svg

Mantenha os nomes em lowercase e sem espaços para facilitar referências no CSS/HTML.
